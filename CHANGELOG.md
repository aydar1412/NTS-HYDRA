# История изменений

Формат основан на Keep a Changelog. Версии – по семантическому versioning.

## [0.1.0-alpha] – 2026-09

Первый публичный выпуск.

### Расчёт

- Поинтервальный расчёт потерь давления: наземная обвязка, бурильная
  колонна, ВЗД, телесистема, насадки долота, затрубное пространство.
- Реология: Гершель-Балкли, степенная, Бингама. Выбор модели по каждому
  интервалу либо автоматически по полноте данных.
- Ламинарный режим решается точно, подбором напряжения на стенке;
  турбулентный – через обобщённое число Рейнольдса.
- Поправка на эксцентриситет колонны в затрубье.
- Поправка на вращение колонны.
- Учёт проходного сечения лопастных элементов.
- Трёхрежимная модель выноса шлама с расчётом равновесной высоты
  шламовой подушки и её влияния на потери и ЭЦП.
- Окно бурения по поровому давлению и давлению гидроразрыва.
- Плотность раствора с учётом сжимаемости и нагрева.
- Давление страгивания после стоянки по СНС 10 мин.
- Восстановление траектории по редким замерам инклинометрии схемой
  «стабилизация + набор» с контролем согласованности MD, TVD и угла.

### Исходные данные

- Единый шаблон Excel из 15 листов в порядке заполнения, на трёх языках.
- Пометка `н/д` для незаполненных величин.
- Поддержка необсаженного интервала в конструкции скважины.
- Чтение файлов прежней структуры.

### Отчёты

- Полный PDF-отчёт: конструкция, профиль, разрез, по два разворота на
  интервал, сводные результаты.
- Краткий PDF-отчёт на две страницы.
- Единицы давления: атмосферы, мегапаскали, бары, psi.
- Руководство пользователя с иллюстрациями из готового отчёта.

### Локализация

- Русский, английский и французский языки отчётов и сообщений.
- Распознавание листов исходных данных и пометок «нет данных» на трёх
  языках.

### Проверка

- Сверка с гидравлическими расчётами из действующей программы бурения:
  десять режимов, четыре диаметра ствола, глубины 772-4240 м.
- Учёт замковых соединений бурильных труб по фактической геометрии.
- Необязательный учёт шероховатости труб для консервативной оценки.


- 66 проверок расчётного ядра: предельные переходы, порог страгивания,
  сверка с промысловыми формулами в других единицах, балансы,
  монотонность.
